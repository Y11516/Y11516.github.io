贝斯家族 - Bugku Crypto Writeup

  • 题目平台：Bugku CTF

二、解题过程（详细步骤）

1. 破解题目名称的“谐音梗”

题目名称“贝斯家族”是英文 Base 的谐音。在 CTF 中，Base 编码是一个庞大的家族，常见的有 Base16、Base32、Base64，以及进阶的 Base85、Base91、Base92 等。

2. 观察密文特征，判断编码类型

密文内容为：@iH<,{bdR2H;i6*Tm,Wx2izpx2!

我立刻对密文进行了特征分析：

  • 标准的 Base64 编码只包含字母、数字、+ 和 /，并以 = 结尾。而这道题的密文中出现了 @、<、{、;、*、,、! 等大量标点符号。
  • 这说明它不属于 Base64，而是使用了更庞大字符集的编码方式。在 Base 家族中，Base91 和 Base92 能够有效利用 ASCII 表中的更多可打印字符（包括特殊符号）。

3. 采用工具进行解码

我直接搜索了“Base91 在线解码”和“Base92 在线解码”，将密文粘贴进去尝试。工具成功将其还原为明文。

三、知识点总结（核心复习素材）

  • 1. Base 编码家族的区别：
    编码类型字符集特征
    Base64包含 A-Z, a-z, 0-9, +, /, =
    Base32包含 A-Z, 2-7, =
    Base85 / Ascii85包含 ASCII 表较广范围的可打印字符
    Base91 / Base92包含大量特殊符号（如 @, <, {, ;, * 等）
  • 2. 特征分析法：遇到未知编码，首先看字符集。只包含十六进制字符 -> 搜 Hex；包含字母数字结尾等号 -> 搜 Base64；包含大量特殊符号 -> 搜 Base91/Base92。通过字符集特征可以快速锁定编码类型。
  • 3. 解题思路：当题目名称本身就给出了强烈的暗示（如“贝斯”对应 Base）时，要敢于优先尝试该家族中较为冷门的编码变种。
