bak文件 - CTFHub Web 入门 Writeup

2026年9月16日 CTFHub Web安全 信息泄露 备份文件

这又是一道极简的源码泄露题。题目名为“bak文件”，页面提示“Flag in index.php source code.”，直接指明了目标：找到 index.php 的备份文件并查看源码。

一、解题步骤

  • 第一步：拼凑备份文件名。 常见的备份后缀有 .bak、~、.old 等。直接在浏览器地址栏输入：
    http://靶场地址/index.php.bak
  • 第二步：下载并审计源码。 浏览器直接下载了该文件。使用 VS Code 打开，或者用终端执行 grep "ctfhub{" index.php.bak，直接在代码中找到了 Flag。

二、核心总结

  • 常见备份文件后缀： 在渗透测试中，要留意 .bak、.swp、.old、.rar、.tar.gz 等后缀，这些都是开发人员留下的“后门”。
  • 源码泄露的自动化： 实战中，不要手动一个个猜，使用 `dirsearch` 等目录扫描工具，配合备份文件字典，可以快速扫出此类文件。

做一道题，就要往自己脑子里装点东西。
