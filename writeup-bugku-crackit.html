Crack it - Bugku Crypto Writeup

2026年9月13日 Bugku CTF Crypto 密码破解 shadow 文件

这道题名为“Crack it”，分类为 Crypto。题目要求破解附件文件，获得密码，最终 Flag 格式为 flag{*}。附件是一个名为 shadow 的文件。

一、题目信息

  • 题目名称：Crack it
  • 题目平台：Bugku CTF
  • 题目类型：Crypto / 密码破解 / Linux 系统安全
  • 题目描述：破解该文件，获得密码，flag格式为：flag{*} 来源：第七届山东省大学生网络安全技能大赛
  • 附件内容：shadow 文件
  • 涉及工具：Mac 终端、Python、openssl、john the ripper

二、解题过程（详细步骤与踩坑记录）

1. 识别文件类型与加密算法

打开附件 shadow，发现这是 Linux 系统的影子文件（存放用户密码哈希）。内容为：

root:$6$HRMJoyGA$26F1gg6CU0bGU0fqFB0Qo9AE2LRZxG8N3H.3BK8t49wG1YbkFbxVFtG0ZqVIq3qQ6k0oetDbn2aVzdhuVQ6U.S.:17770:0:99999:7:::

分析格式可知：$6$ 表示密码使用 SHA-512 哈希算法加密，$HRMJoyGA 是盐值（Salt），后面的是加密后的哈希串。

2. 尝试在线破解与本地 Python 脚本（均失败）

我首先尝试了 cmd5.com 和 CrackStation 等在线平台，但它们对带盐的 $6$ 哈希支持不佳。随后我编写了本地 Python 脚本（使用 crypt 库）进行字典爆破，尝试了 123456、root、admin 等常见密码，均提示“没有匹配成功”。

3. 发现根本原因：Mac 环境兼容性问题

经过排查，我发现了导致爆破失败的真正原因：Mac 系统自带的 Python 环境中的 crypt 库，默认不支持 $6$（SHA-512）算法！ 因此脚本在内部计算时全部返回了错误的结果。这是一个非常经典的“环境坑”。

4. 使用正确工具进行爆破（成功）

我改用专业工具进行爆破。在 Kali Linux 中，可以使用 john（John the Ripper）：

john --format=sha512crypt --wordlist=/usr/share/wordlists/rockyou.txt shadow

同时，在 Mac 上可以直接用 openssl 验证密码是否为字典中的 hellokitty：

openssl passwd -6 -salt HRMJoyGA hellokitty

输出的哈希值与题目完全一致！这证实了密码就是 hellokitty。

最终 Flag： flag{hellokitty}

三、原理深度剖析（为什么爆破能成功？）

核心概念：哈希算法与字典攻击

  1. 带盐哈希（Salted Hash）：$6$ 格式包含盐值。盐值的作用是让相同的密码产生不同的哈希值，从而防止攻击者使用预先计算好的彩虹表。
  2. 字典攻击（Dictionary Attack）：虽然加盐废掉了彩虹表，但无法阻止字典攻击。因为人类设置密码有惰性（如生日、名字、常用词）。攻击者使用 rockyou.txt 等真实泄露密码字典，将字典中的每一个词加上盐进行哈希计算，并与目标比对。一旦匹配，就找到了明文密码。
  3. 防御方法：设置强密码、限制登录错误次数、使用更安全的慢哈希算法（如 bcrypt、argon2）。

四、知识点总结（核心复习素材）

  • 1. shadow 文件结构：Linux 用户密码存储文件，格式为 用户名:哈希:最后修改日期:最小密码年龄:最大密码年龄:警告期:不活动期:过期日期:保留字段。
  • 2. 加密算法标识：$1$ 代表 MD5，$5$ 代表 SHA-256，$6$ 代表 SHA-512。识别算法标识是破解的第一步。
  • 3. Mac 环境下的避坑指南：处理 $6$ 哈希时，避免使用 Python 的 crypt 库，优先使用 openssl 进行验证，或者安装 john / hashcat 进行专业爆破。
