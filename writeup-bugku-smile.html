滑稽 - Bugku Web 入门 Writeup

2026年9月10日 Bugku CTF Web安全 信息搜集

这道题的名字叫“滑稽”，打开靶场后确实让人很“无语”——满屏幕都是飞来飞去的黄色笑脸，完全看不到任何输入框和提示。但作为 Web 安全的第一课，它完美地演示了最基础的信息搜集技巧。

一、题目信息

  • 题目名称：滑稽
  • 题目平台：Bugku CTF
  • 题目类型：Web / 源码信息泄露
  • 靶场地址： http://160.202.254.160:12597 (环境有效期内)
  • 题目描述： flag0

二、使用工具

  • 浏览器（Mac 系统）
  • 浏览器开发者工具（快捷键 Fn + F12 或右键“检查”）

三、解题步骤

1. 面对“万脸奔腾”，寻找突破口

打开靶场，满屏滑稽笑脸。遇到这种没有任何交互界面的题，第一反应必须是：查看网页源码。

2. 召唤开发者工具（F12）

在页面空白处按 Fn + F12（或右键点击页面，选择“检查”），唤出浏览器的开发者工具面板。

3. 在 Elements 面板中找到 Flag

在开发者工具的 Elements（元素）标签下，仔细阅读 HTML 代码结构。滑到最上面的 <body> 标签附近，发现了一行非常明显的注释：

<body id="body" onload="init()">
<!--flag{30234a3a2d2d85a6c494994f6b7920b0}-->

直接把括号里的内容复制出来，提交到题目平台即可通关。

四、知识点总结（往脑子里装的东西）

  • HTML 注释泄露：<!-- ... --> 是 HTML 的注释语法。程序员经常把测试账号、内部接口甚至 Flag 写在注释里，忘了删除就上线。这称为“敏感信息泄露”。
  • F12 开发者工具：这是 Web 安全的“瑞士军刀”。无论题目伪装得多好，只要用 F12 查看源码，就能剥开表象看到真正的后端代码或隐藏元素。
  • 信息搜集是第一生产力：在渗透测试中，拿到目标先“踩点”，查看源码、注释、网络请求，是永不落空的基本功。

做一道题，就要往自己脑子里装点东西。
