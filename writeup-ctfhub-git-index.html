Git泄露-Index - CTFHub Web 入门 Writeup

2026年9月16日 CTFHub Web安全 信息泄露 Git泄露

这是我攻克 Git 泄露系列的最后一题——Index。这道题非常特殊，它考察的是 Git 工作流中的“暂存区”。这篇 Writeup 将用最通俗的比喻，详细解释每一步代码背后的原理，以及我在解题过程中踩过的一系列新手坑。

一、极简名词科普（写给未来的自己）

  • Git： 一个“游戏存档系统”。开发人员写完代码就存个档（git commit），记录历史。
  • .git 文件夹： 存放所有历史存档的“保险箱”。
  • Git 泄露： 开发者粗心，把“保险箱”一起传到了服务器上，被我们直接下载。
  • git-dumper： 一款专门用来“偷保险箱”的 Python 工具。它模拟浏览器绕过 WAF，把成千上万的历史碎片下载下来，在本地自动拼装成一个完整的 Git 仓库。
  • Log（正式存档）： 用 git log 查看历史提交记录。
  • Stash（临时草稿）： 用 git stash list 查看临时藏匿的工作区。
  • Index（购物车/暂存区）： 代码改完放进了购物车（git add），但还没有正式结账（git commit）。本题的 Flag 就藏在这个购物车里。

二、解题过程（详细步骤与踩坑全记录）

1. 踩坑第一步：地址写错导致 404

我按照网上的教程在终端输入了 git-dumper http://challenge-xxx.../.git/ git_index。结果终端报错 404 Not Found。

原因分析： challenge-xxx 是教程里的占位符，不是真实的靶场地址！我犯了一个极其低级的错误，没有把地址替换成当前题目给出的真实 URL。

解决： 替换为真实的靶场地址 http://challenge-3cc8981cf357b284.sandbox.ctfhub.com:10800/.git/，重新执行。

2. 成功破局：下载并还原 Git 仓库

cd ~/Downloads
rm -rf git_index
git-dumper http://challenge-3cc8981cf357b284.sandbox.ctfhub.com:10800/.git/ git_index

终端开始飞快下载一系列 objects/ 文件，最终提示“Running git checkout .”，成功将静态文件还原为了完整的 Git 仓库。

3. 踩坑第二步：用错命令，找不到暂存区

进入文件夹后，我习惯性地输入了 git log，结果提示“fatal: your current branch 'master' does not have any commits yet”（当前分支没有任何提交）。

原因分析： 这是 Index 题！开发人员只执行了 git add（放进了购物车），但没有执行 git commit（结账），所以根本没有提交历史。

4. 终极破局：查看“购物车”里的文件

既然没有提交记录，我们就去查看暂存区（Index）。执行以下命令：

git ls-files

终端成功列出了暂存区里的文件名。直接查看该文件的内容，或者使用 git diff --cached 查看暂存区的代码差异，成功提取出 Flag。

最终 Flag： ctfhub{...} （请替换为实际获取的值）

三、代码逐行大白话解析（新手必读）

  • cd ~/Downloads：打开电脑的“下载”文件夹，准备干活。
  • rm -rf git_index：强制删除旧的 git_index 文件夹，保证从头开始，防止文件冲突。
  • git-dumper <地址> <文件夹名>：把网站上的“保险箱”整个下载回来，放到本地。
  • cd git_index：进入这个刚刚拼装好的本地仓库。
  • git ls-files：列出“购物车”（暂存区）里有哪些文件。这是 Index 题的核心命令！
  • cat 文件名：查看具体文件的内容。（注意：把“文件名”换成 ls-files 里看到的真实名字）。
  • git diff --cached：对比购物车里的东西和最后一次存档的区别，Flag 通常以代码差异的形式出现。
  • grep -r "ctfhub{" .：终极暴力搜索大法。在当前目录下所有文件中强行搜关键字，不讲究技巧，但往往能一击必杀。

四、踩坑启示录（极其宝贵的实战经验）

💡 不要盲目复制网上的命令： 遇到 challenge-xxx 这种地址必须替换成真实地址，否则一切操作都是白费。

💡 “购物车”思维： Log、Stash、Index 代表了 Git 的三个不同区域。查历史用 Log，查临时草稿用 Stash，查购物车用 git ls-files 或 git diff --cached。

五、总结对比：Git 三大泄露（Log / Stash / Index）

  • Log（正式存档）： Flag 藏在提交历史里。查 git log 和 git show。
  • Stash（临时收纳箱）： Flag 藏在临时草稿里。查 git stash list 和 git stash show -p。
  • Index（购物车）： Flag 藏在暂存区里。查 git ls-files 和 git diff --cached。

做一道题，就要往自己脑子里装点东西。
