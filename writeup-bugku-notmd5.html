这不是md5 - Bugku Crypto Writeup

2026年9月11日 Bugku CTF Crypto 编码转换

这道题的名字和给出的字符串形成了一种强烈的“反差”。它看似是一个 MD5 哈希值，实际上却是一次基础的十六进制转 ASCII 编码。这篇 Writeup 记录了我识别编码、避开陷阱并完成转换的完整思考过程。

一、题目信息

  • 题目名称：这不是md5
  • 题目平台：Bugku CTF
  • 题目类型：Crypto / 十六进制编码（Hex Encoding）
  • 题目描述：666c61677b616537333538376261353662616566357d
  • 涉及工具：Python、在线十六进制转 ASCII 工具

二、解题过程（详细步骤）

1. 识别字符串特征，避免思维定势

拿到题目，我看到一长串由数字和字母组成的字符串，从外形上看非常像一个哈希值。

但题目名字叫“这不是md5”，这是一个巨大的提示。

  • 标准的 MD5 值是 32 位十六进制字符（128位）。
  • 我拿到了这串字符：666c61677b616537333538376261353662616566357d。
  • 我用手指比划了一下，发现它的长度是 42 位，并不是 32 位！

排除 MD5 之后，结合它只由 0-9 和 a-f 组成，并且长度为偶数（可以两两分组），我迅速锁定了它是一种最简单的编码方式：**ASCII 码的十六进制表示**。

2. 手动验证特征

我尝试将字符串两两分组，并查 ASCII 码表：

  • 66 = 'f'
  • 6c = 'l'
  • 61 = 'a'
  • 67 = 'g'
  • 7b = '{'

看到前三组是 flag，我确信自己已经找对方向了。

3. 使用 Python 一键转换

虽然可以手动查表转换，但使用 Python 脚本能确保万无一失。我打开了 Mac 终端：

python3 -c "print(bytes.fromhex('666c61677b616537333538376261353662616566357d').decode('utf-8'))"

回车后，终端直接输出了明文。

最终 Flag： flag{ae73587ba56baef5}

三、知识点总结（核心复习素材）

  • 1. 识别 MD5 与 Hex 的区别：MD5 固定是 32 位十六进制字符串，本题的字符串长度是 42 位。同时，题目名称“这不是md5”本身也是极关键的提示。遇到类似情况，优先尝试十六进制转 ASCII。
  • 2. 十六进制转 ASCII 的原理：计算机中所有字符都有一个对应的 ASCII 码（如 `f` 是 `0x66`）。将十六进制字符串两两分组，每一组对应一个字符，即可完成编码还原。
  • 3. 养成使用 Python 的习惯：对于编码转换类题目，Python 的 bytes.fromhex().decode() 是极其高效的解法，远比手动查表或使用不可靠的网页工具准确。
