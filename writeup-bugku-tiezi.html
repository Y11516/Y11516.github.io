二、解题过程（详细步骤与逻辑剖析）

1. 厨房 —— 零宽字符文本隐写

操作步骤：打开 厨房/垃圾桶/垃圾桶.txt，全选复制里面的文字，打开在线“零宽字符Unicode隐写解密工具”，粘贴到右侧“隐写文本”框，点击“解密”。

目的是什么？出题人把一句关键的密码（Wi-Fi密码）通过不可见的特殊字符隐藏在了一段看似正常的文本里，需要专用工具把它翻译出来。

背后的逻辑：零宽字符（如 U+200B 零宽空格、U+200C 零宽非连接符等）在浏览器和文本编辑器中肉眼不可见，但计算机能识别。通过加密算法将这些字符映射为二进制，就能隐藏在文本中。

解密结果：得到Wi-Fi密码 donotplayxingtietoomuchtime（别玩星铁玩太久）。

2. 自己的卧室 —— ZIP解密与解压

操作步骤：在 自己的卧室/星穹铁道 目录下找到 请输入Wi-Fi密码.zip，输入上一步得到的密码进行解压，得到一张图片 星穹铁道.jpg。

目的是什么？利用密码解锁压缩包，提取出下一个阶段的素材（图片）。

背后的逻辑：这是CTF中常见的“套娃”模式，前一个隐写步骤得到的字符串，往往就是后一个加密文件的密码。

💡 解题小技巧：题目提示说“真没必要看的就不用太费精力了”，因此 客厅 和 爸妈的卧室 以及 111.txt 这些属于干扰项，可以直接跳过。

3. 星穹铁道.jpg —— 图片隐写与文件分离

操作步骤：拿到JPG图片后，先用 binwalk 命令扫描，再用 foremost 命令分离（或用010 Editor手动搜索文件头分离）。

终端操作（在Kali Linux的终端）：

binwalk 星穹铁道.jpg
foremost -i 星穹铁道.jpg -o output

目的是什么？检查图片文件末尾是否拼接了其他文件，并将隐藏的文件提取出来。

背后的逻辑：文件系统通常按“文件头+文件数据+文件尾”来识别文件。攻击者经常把另一个文件（如ZIP、PNG）的完整数据直接粘贴在JPG的结尾。JPG看图软件读到结束标记（FF D9）就停止，后面的附加数据不会被显示，但用二进制工具读取全部数据时，就能发现。

得到结果：foremost会分离出隐藏的图片，打开发现是一个**二维码**，扫码即可得到最终的Flag。

三、踩坑与代码/命令迭代全过程（为什么总是失败？）

在 Mac 系统下操作时，很多同学（包括我）会经历多次报错，这里记录下踩坑全过程以及背后的原因：

第一次迭代：直接尝试运行 binwalk

报错：zsh: command not found: binwalk

为什么错？Mac系统默认没有安装Linux常见的CTF工具集，终端找不到这个命令。

第二次迭代：尝试安装 binwalk / 安装 Ruby 环境

操作：使用 Homebrew 安装 brew install ruby。

遇到的问题：安装Ruby成功，但终端提示各种路径冲突（shadowed by /usr/bin/ruby）。因为Mac自带了老版本的Ruby，Homebrew安装了新版本，但系统环境变量没更新，导致接下来使用 gem install zsteg 依旧失败。

第三次迭代：改用替代方案（在线工具和010 Editor）

改动：放弃本地终端安装环境，转向本地 GUI 工具（010 Editor）或在线工具（Aperi'Solve）。

为什么改？CTF的目标是拿Flag，不是修环境。Aperi'Solve 在服务器端已经装好了所有工具，我们在网页上传图片，就等于把本地的 binwalk 和 foremost 操作统统交给了服务器代跑。

010 Editor的操作逻辑：利用十六进制编辑器的搜索功能，按 Cmd+F 搜索JPG的文件头 FF D8 FF，或PNG的文件头 89 50 4E 47。找到第二个匹配的偏移量后，从这里一直选到文件末尾，复制十六进制字节，新建文件粘贴并另存为 flag.png，就手动完成了文件分离。

四、名词解释大全（你需要知道的基础概念）

1. 零宽字符 (Zero-width characters)

Unicode标准中的不可见控制字符，如零宽空格、零宽连字符。常被用于文本水印、隐写数据。

2. binwalk

一款固件分析工具，在CTF中主要用于扫描文件是否包含其他嵌入文件（如ZIP、PNG、证书等），能准确告诉你嵌入文件在哪个字节偏移量。

3. foremost

一款基于文件头尾特征的数据恢复工具，和 binwalk 是黄金搭档。binwalk 负责“看”，foremost 负责“切”（分离提取文件）。

4. 010 Editor

专业的十六进制编辑器。可以直观地看到文件的每一个字节，支持模板解析（如解析PNG结构、JPG结构），在CTF里是手动分离文件、修改文件头大小的利器。

5. 文件头（Magic Number）

文件开头的一串特定十六进制字节，用来告诉系统“我是什么文件”。比如JPG是 FF D8 FF，PNG是 89 50 4E 47，ZIP是 50 4B 03 04。文件分离就是靠搜寻这些“魔数”定位的。

6. 二维码 (QR Code)

一种矩阵条形码，本题最后提取出来的隐藏图片就是一张二维码，用手机扫一扫即可解码出文本（Flag）。
