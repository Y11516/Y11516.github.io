Burp-Labs Level 3 - 用户名枚举与密码爆破

2026年10月3日 Burp-Labs 用户名枚举 Sniper模式

一、题目信息

  • 题目名称：Burp-Labs Level 3 (用户名枚举)
  • 核心考点：用户名枚举与固定用户名密码爆破
  • 涉及工具：Burp Suite Community、浏览器

二、解题步骤

1. 分析题目考什么

从 Level 3 开始，靶场引入了“用户名枚举”的概念。在实际渗透中，攻击者往往不知道系统有哪些账号。如果系统对“用户不存在”和“密码错误”的响应不同（如回显不同、状态码不同、响应时间不同），就可以先枚举出有效的用户名。

注：本靶场平台描述直接给出了提示：“level3 用户名为 test”。这是一个白盒测试场景下的明显信息泄露。

2. 怎么解（详细步骤）

详细实操步骤

第一步：确定有效用户名

由于靶机提示已经给了 test，我们直接使用该用户名。如果想练习枚举技巧，可以尝试输入 admin 和 test，观察服务器返回的报错信息是否有差异（如“用户不存在”与“密码错误”）。

第二步：配置 Sniper 模式爆破密码

浏览器输入 test 和任意密码，抓包发送 Intruder。清除所有标记，仅给密码加 §，Attack type 选择 Sniper。

第三步：加载字典并配置过滤器

Payloads 加载密码字典。Options -> Grep - Match 填入：

success, flag, 欢迎, 登录成功

第四步：开始攻击与结果查看

点击 Start Attack。同样，如果 Length 长度一致，通过 Grep - Match 列寻找带 ✅ 的请求，即可获得正确密码。

3. 踩坑记录与心得

关于“固定用户名”的误区

误区：面对“用户名枚举”的关卡，很多人第一反应是直接上 Cluster bomb 模式（用户名和密码同时爆破），这在 Burp 社区版下会导致请求量爆炸，且容易漏掉正确答案。

改进：先通过观察回显差异（或看靶场提示）枚举出有效的用户名，再回退到 Sniper 模式，只爆破密码，效率翻倍。

4. 经验总结（怎么迁移）

  • 信息收集的重要性：在做题时，一定要仔细看题目描述和提示，有时“用户名是 test”这种提示能帮你省去几个小时的盲跑时间。在真实攻防中，通过社工库、网页接口报错等手段进行信息收集，同样是关键的第一步。
  • 多关注状态码变化（200 vs 302）、响应内容变化和响应时间差异。
