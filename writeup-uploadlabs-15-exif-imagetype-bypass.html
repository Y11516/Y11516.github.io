Upload-Labs Pass-15

2026年9月27日 Upload-Labs Web安全 文件上传 图片马

一、题目信息

  • 题目名称：Upload-Labs Pass-15 (exif_imagetype() 图片马绕过)
  • 题目平台：Upload-Labs 本地靶场
  • 题目类型：Web安全 / 文件上传漏洞 / 文件头伪造 / 图片马
  • 靶场链接：http://localhost:8082/Pass-15/index.php（本地环境）
  • 涉及工具：Mac 终端（Terminal）、Python（可选）

二、解题步骤

1. 分析题目考什么

本题的核心考点是利用 exif_imagetype() 函数的特性绕过检测。与 Pass-13 的 getimagesize() 和 Pass-14 的严格结构校验不同，exif_imagetype() 只会读取文件的前几个字节（文件签名/Magic Bytes）。因此，只要在 PHP 代码前伪造合法的图片文件头，即可轻松绕过。

2. 怎么想（破题思路）

  • 本题看起来和 Pass-14 完全一样，但后端检测函数换成了 exif_imagetype()。
  • 因为 exif_imagetype() 只校验文件头（比 getimagesize() 宽松），所以直接用 Pass-14 中制作的图片马。
  • 绕过前端 JS 拦截，依次上传三种后缀的图片马，全部成功即可通关。

3. 怎么解（详细步骤与踩坑记录）

踩坑记录一：感觉题目完全一样，是否是重复劳动？

踩坑情况：Pass-13、14、15 的界面和任务要求几乎一模一样，让人感觉是在重复做同一道题。

原因分析：靶场故意设计了三个连续关卡，分别对应三种不同的后端检测函数（getimagesize、getimagesize 严格版、exif_imagetype）。学习目的是让我们摸清不同检测函数的容错率。

改进方式：理解“图片马”是一种通用解法。只要掌握了伪造文件头的技术，无论后端用哪个函数，都能轻松绕过。

详细实操步骤（Payload逐字解释）

第一步：复用 Pass-14 的图片马

直接在终端中使用之前生成好的图片马文件：

echo -e "GIF89a" > shell.gif
printf '\x89PNG\r\n\x1a\n' > shell.png
# 对于 JPG，继续使用真实图片追加木马的方式：
echo "" >> real.jpg

第二步：上传并验证

回到靶场页面，按 F12 覆盖前端 JS：checkFile = function() { return true; }。依次上传 shell.gif、real.jpg、shell.png，全部提示“上传成功”即通关。

4. 怎么迁移（跨领域联想）

  • 检测函数的不同层级：exif_imagetype 是最浅层的检测（只看头部），getimagesize 会稍深一点（解析图像信息），而真正安全的做法是重新渲染图片。这告诉我们在代码审计中，要格外注意开发人员用的是哪种检测函数。
  • 攻击链思维：图片马本身无法直接 RCE，必须配合 LFI 或解析漏洞。这说明在真实渗透中，往往需要把多个漏洞组合起来利用，才能达成最终目标。

三、名词大全与原理深度复盘

1. exif_imagetype() 函数

PHP 内置函数，用于读取图像文件的前几个字节（Magic Bytes）来判断文件类型。它比 getimagesize() 更快，但只检查文件头，因此非常容易通过伪造文件头来绕过。

2. 图片马 (Image Webshell)

将 WebShell 代码嵌入到合法图片文件中的攻击手法。图片可以正常显示，但当它被 PHP 的 include() 等文件包含函数加载时，其中的恶意代码会被执行。

四、题目思考

1. 这跟前面的题有什么区别？

  • 与 Pass-14 的区别：Pass-14 使用 getimagesize()，对文件结构要求更严格（JPG 只有简单的头容易失败）。Pass-15 使用 exif_imagetype()，只要文件头正确就能过，因此之前的图片马可以直接复用。

2. 这种题目的出现原因（为什么存在）

开发者试图使用更轻量的 exif_imagetype() 来提升性能，却不知道这个函数的安全性非常薄弱。这警示我们：安全性和性能往往需要权衡，在核心业务逻辑中，安全必须是首要考虑的因素。

3. 这种应用在实际中如何体现？

在实战中，如果遇到只检测文件头的站点，攻击者可以轻松上传图片马。防御方应使用图像处理库对图片进行重新编码，彻底抹除图片中可能夹带的恶意代码。

4. 如何抽象理解概念（大白话）

把靶场比作一个“门卫”：

  • Pass-15 的门卫只扫一眼你衣服上的徽章（文件头）。
  • 只要你把徽章戴好（伪装文件头），就能大摇大摆地走进去。
  • 这就是为什么 Pass-15 比 Pass-14 简单——Pass-14 的门卫还会摸一摸你的口袋（校验结构），而 Pass-15 的门卫只看胸牌。

做一道题，就要往自己脑子里装点东西。
