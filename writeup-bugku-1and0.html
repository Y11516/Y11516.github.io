二、解题过程（详细步骤与三次踩坑全记录）

1. 第一步：观察文件，识别数据矩阵

打开附件 1和0的故事.txt，里面是密密麻麻的 0 和 1。我仔细数了一下，一共是 25 行，每行 25 个数字。

逻辑分析：这是一个 25x25 的 01 矩阵。在二维码的标准中，21x21 是 Version 1，25x25 是 Version 2 二维码。这意味着，这个文本文件其实是一张二维码的“数据点阵图”。

2. 第二步：初步尝试——直接生成图片（踩坑与失败）

我首先写了一个简单的 Python 脚本，把这个 0/1 矩阵画成一张黑白图片：

from PIL import Image

matrix = []
with open('1和0的故事.txt', 'r') as f:
    for line in f:
        line = line.strip()
        if line:
            matrix.append([int(c) for c in line])

size = len(matrix) # 25
img = Image.new('RGB', (size, size), color='white')
pixels = img.load()

for y in range(size):
    for x in range(size):
        if matrix[y][x] == 0: # 假设 0 是黑点
            pixels[x, y] = (0, 0, 0)

img = img.resize((500, 500), Image.NEAREST)
img.save('raw_qr.png')
print("初步生成完成！")

问题现象：生成的 `raw_qr.png` 用手机扫码或在线解码工具完全无法识别。

原因分析：二维码除了中间的数据区域，还必须包含三个 7x7 的定位角（Finder Pattern），分别位于左上角、右上角和左下角。这三个定位角让扫码器能判断二维码的方向、大小和版本。这个文件里缺少了这三个定位角，所以扫码器无法识别。

3. 第三步：尝试网页工具 QRazyBox（中途受挫）

我按照评论区的提示，尝试使用在线二维码修复工具 QRazyBox。然而，在浏览器里找了一圈，发现官方网站（merricx.github.io/qrazybox/）提供的是文档说明，或者工具界面加载不出来，找不到“从文本导入”的入口。这导致我在网页工具上卡了很久。

4. 第四步：回归 Python，手动补全定位角（最终成功）

既然网页工具不好用，我就用 Python 自己“画”出这三个定位角！我修改了之前的代码，在画原始数据的基础上，强行在对应的三个角落涂上标准的黑白相间的“回”字形定位角：

from PIL import Image

# 1. 读取 0 1 矩阵
matrix = []
with open('1和0的故事.txt', 'r') as f:
    for line in f:
        line = line.strip()
        if line:
            matrix.append([int(c) for c in line])

size = len(matrix) # 25
img = Image.new('RGB', (size, size), color='white')
pixels = img.load()

# 2. 画入原始数据
for y in range(size):
    for x in range(size):
        if matrix[y][x] == 0:
            pixels[x, y] = (0, 0, 0)

# 3. 核心逻辑：强行画入三个 7x7 定位角（左上、右上、左下）
def draw_finder_pattern(start_x, start_y):
    for y in range(7):
        for x in range(7):
            # 定位角规则：外圈是黑色实线，中间3x3是白色，最核心2x2是黑色
            if (x == 0 or x == 6 or y == 0 or y == 6) or (2 <= x <= 4 and 2 <= y <= 4):
                pixels[start_x + x, start_y + y] = (0, 0, 0)
            else:
                pixels[start_x + x, start_y + y] = (255, 255, 255)

draw_finder_pattern(0, 0)       # 左上角定位角
draw_finder_pattern(size-7, 0)  # 右上角定位角
draw_finder_pattern(0, size-7)  # 左下角定位角

# 4. 放大保存
img = img.resize((500, 500), Image.NEAREST)
img.save('fixed_qr.png')
print("✅ 二维码已生成，请打开 fixed_qr.png 扫码！")

在终端运行 python3 create_qr.py，终端提示“二维码已生成”。

5. 第五步：扫码获取 Flag

在终端输入 open fixed_qr.png，Mac 弹出图片。用手机微信扫一扫，或者在线的“二维码解码工具”上传图片，成功扫出最终的 Flag！

最终 Flag： flag{QR_c0de_1s_1nterest1n9}

三、超详细名词解释与底层逻辑

1. 二维码（QR Code）

Quick Response Code 的缩写。它是一种矩阵条码，用黑白像素点表示数据。这三个方角的学名是“位置探测图形”（Finder Pattern），用来帮助扫描设备定位二维码的边界、角度以及纠错。

2. 25x25 矩阵与版本

二维码的尺寸随版本（Version）增加。Version 1 是 21x21，Version 2 是 25x25，每升一版增加 4 个像素。所以看到 25x25，我们立刻知道它是 Version 2，需要补全标准的 7x7 定位角。

3. Python 的 Pillow（PIL）库

Python 中最常用的图像处理库。我们用 Image.new 创建画布，用 pixels[x, y] 来精确控制每一个像素点的颜色（黑色或白色）。

4. 里德-所罗门码（Reed-Solomon）

二维码底层使用的纠错算法。即使二维码部分区域被污损（比如缺失了定位角），它依然能通过冗余数据计算出缺失的部分。这也是为什么我们补全定位角后，它能顺利扫出来的原因。
