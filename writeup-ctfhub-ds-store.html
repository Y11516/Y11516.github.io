DS_Store - CTFHub Web 入门 Writeup

2026年9月16日 CTFHub Web安全 信息泄露 Mac系统文件

这又是一道经典的源码备份文件泄露题。目标文件是 Mac 操作系统特有的 .DS_Store 隐藏文件。通过下载并解析该文件，可以获取服务器目录下的全部文件清单，从而发现隐藏的 Flag 文件。

一、解题步骤

  • 第一步：下载隐藏文件。 页面提示“试着寻找 flag”。在浏览器地址栏访问：
    http://靶场地址/.DS_Store
    或者用终端：wget http://靶场地址/.DS_Store
  • 第二步：解析文件，获取文件名清单。 由于 .DS_Store 是二进制文件，无法直接双击打开。尝试用 Python 脚本解析失败，最终使用终端命令成功提取：
    strings DS_Store | grep -i "flag"
    解析出服务器目录下存在一个名为 flag_xxxx.txt（或类似名字）的隐藏文件。
  • 第三步：访问真文件，获取 Flag。 直接在浏览器地址栏拼接解析出的文件名，成功获取了最终的 Flag。

最终 Flag： ctfhub{...} （请替换为实际获取的值）

二、核心总结与踩坑记录

  • .DS_Store 泄露漏洞： 这是 Mac 用户特有的信息泄露风险。开发者在 Mac 上打包源码并上传服务器时，如果没清理 .DS_Store，攻击者就能通过它摸清服务器的文件结构。
  • 踩坑记录： 试图用 Python 的 ds_store 库解析，但报错 AttributeError: module 'ds_store' has no attribute 'open'。原因是库的用法不正确，不能直接调用 open，需要先实例化 DSStore 对象。最终改用终端命令 strings 快速提取文本内容。

做一道题，就要往自己脑子里装点东西。
