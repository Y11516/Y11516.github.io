逆向入门 - Bugku MISC Writeup

2026年9月13日 | MISC | Base64隐写 / 二维码

这道题名为“逆向入门”，但实际是一道典型的“伪装文件”类隐写题。附件是 admin.exe，题目提示 Flag 格式为 bugku{}。

一、题目信息

  • 题目名称：逆向入门
  • 题目平台：Bugku CTF
  • 题目类型：MISC / Base64转码 / 二维码识别
  • 题目提示：bugku{}
  • 附件内容：admin.exe

二、解题过程（完全基于 Mac 终端实操）

1. 识别文件真实类型

进入下载目录，使用 Mac 终端输入 file "admin.exe" 查看真实文件类型。结果显示它并不是 PE32 可执行文件，而是文本文件，说明文件后缀名是伪装的。

2. 查看文件真实内容

在终端中使用 cat "admin.exe" 读取内容，屏幕上输出了一长串以 iVBORw0KGgo 开头的字符串。iVBORw0 是 PNG 图片的 Base64 编码标志，说明这个“exe”实际上是一张经过 Base64 编码的 PNG 图片。

3. 使用 Python 一键提取图片（避免粘贴报错）

起初我尝试手动复制这串 Base64 到在线工具，但报了格式错误。于是直接在终端中调用 Python 进行清理和转换：

python3 -c "import base64; data = open('admin.exe', 'rb').read().replace(b'\n', b'').replace(b'\r', b''); idx = data.find(b'iVBORw0'); out = open('flag.png', 'wb'); out.write(base64.b64decode(data[idx:]) if idx != -1 else b''); out.close(); print('提取成功！图片已保存为 flag.png')"

终端成功提示“提取成功！图片已保存为 flag.png”。

4. 打开图片并扫描二维码

在终端输入 open flag.png 直接打开图片。图片是一张二维码，使用手机扫码，直接得到了最终的 Flag。

最终 Flag： bugku{inde_9882ihsd8-0}

三、知识点总结（核心复习素材）

  • 1. 文件扩展名欺骗：文件后缀名（如 .exe）是可以随意修改的。在 CTF 中，不要盲目相信后缀名，应用 file 命令或十六进制工具查看文件的真实类型。
  • 2. Base64 编码特征：PNG 图片的 Base64 编码通常以 iVBORw0 开头，JPEG 图片通常以 /9j/ 开头。掌握这些特征能快速判断数据的真实身份。
  • 3. 自动化脚本的优势：处理长字符串时，使用 Python 脚本直接读取、解码、写出文件，能完美避开手动复制粘贴产生的换行、空格或漏字符等问题。
