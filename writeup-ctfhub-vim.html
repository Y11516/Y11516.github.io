vim缓存 - CTFHub Web 入门 Writeup

2026年9月16日 CTFHub Web安全 信息泄露 Vim缓存

这道题是备份文件下载系列的另一经典场景。开发人员在线上使用 vim 编辑器修改代码时，如果发生异常退出，会在服务器上残留一个交换文件（Swap File），导致源码泄露。

一、解题步骤

  • 第一步：拼凑 Vim 缓存文件名。 页面提示“flag 在 index.php 源码中”。在浏览器地址栏访问：
    http://靶场地址/.index.php.swp
  • 第二步：下载并提取源码。 浏览器成功下载该文件（注意：浏览器可能会自动去掉文件名开头的点，变为 index.php.swp）。在 Mac 终端执行搜索命令：
    strings index.php.swp | grep "ctfhub{"
    成功提取出 Flag。

最终 Flag： ctfhub{31ea916c032adc722f1c8374}

二、核心总结与踩坑记录

  • 常见 Vim 缓存文件名： .swp、.swo、.swn。
  • 踩坑记录： 在终端执行 strings .index.php.swp 报错 No such file or directory。原因是浏览器下载时可能丢失了开头的点。使用 ls -la 检查真实文件名后，改用 index.php.swp 成功运行。

做一道题，就要往自己脑子里装点东西。
