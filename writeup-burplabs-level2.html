Burp-Labs Level 2 - 响应过滤与盲爆破

2026年10月3日 Burp-Labs Web安全 Burp Suite 盲爆破

一、题目信息

  • 题目名称：Burp-Labs Level 2 (响应过滤)
  • 核心考点：长度一致场景下的过滤器应用
  • 涉及工具：Burp Suite Community、浏览器

二、解题步骤

1. 分析题目考什么

本题是 Level 1 的进阶版。区别在于服务器统一了错误响应，所有请求的 Length（响应长度）完全一致（例如全是 177），状态码也都是 200。肉眼排序法失效，必须使用 Burp 的 Grep - Match（响应过滤器）来寻找不同。

2. 怎么解（详细步骤）

详细实操步骤

第一步：抓包与配置 Positions

参考靶机描述提示（Level 3 用户名为 test），优先尝试固定用户名 test。随便输入密码抓包，发送到 Intruder。清除所有标记，只给密码加 §，Attack type 选 Sniper。

第二步：加载字典并配置过滤器（关键）

Payloads 选项卡加载密码字典。随后点击 Options 标签页，找到 Grep - Match，勾选匹配功能，填入正反义词：

success, flag, 欢迎, 登录成功, 密码错误, 失败

第三步：发起攻击与结果分析

点击 Start Attack（社区版提示限速点OK）。跑完后，忽略 Length 列，直接看新增的 Grep - Match 列。哪一行出现了 ✅ 且包含成功关键字，那就是正确密码。

3. 踩坑记录

Burp 社区版龟速限速

情况：点击攻击弹出 Demo 版本提示，攻击速度极其缓慢。

改进：控制字典大小（50条左右即可），或者使用 Turbo Intruder 插件绕过限速。

4. 经验总结（怎么迁移）

  • 盲盒思维：当所有盒子的外观（长度、状态码）完全一样时，你需要用“听诊器”（Grep - Match）去听里面的声音，找出装有特定物品的那一个。
  • 在面对“盲注”或“无回显”漏洞时，工具的特征过滤能力是渗透测试的核心基本功。
