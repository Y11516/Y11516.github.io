聪明的小羊 - Bugku Crypto Writeup

2026年9月10日 Bugku CTF Crypto 栅栏密码

这又是一道 Crypto 方向的密码学题。题目名字叫“聪明的小羊”，并且描述里写着“一只小羊翻过了2个栅栏”。结合这些提示，我迅速锁定了这是密码学中经典的“栅栏密码”。

一、题目信息

  • 题目名称：聪明的小羊
  • 题目平台：Bugku CTF
  • 题目类型：Crypto / 栅栏密码（Rail Fence Cipher）
  • 题目描述：一只小羊翻过了2个栅栏 fa{fe13f590lg6d46d0d0}
  • 涉及工具：手动推演 / 在线栅栏密码解密工具

二、解题步骤

1. 识别密码类型

看到“栅栏”两个字，以及描述中给出的密文 fa{fe13f590lg6d46d0d0}，立刻确认这是栅栏密码。题目说“翻过了2个栅栏”，说明是**2栏栅栏密码**。

栅栏密码的核心原理是将明文按奇数和偶数位置拆分成两行，然后交替拼接成密文。解密时反向操作即可。

2. 动手解密

我们收到的密文长度为22个字符，先将其对半拆分为两部分：

  • 前半段（11个字符）：fa{fe13f590
  • 后半段（11个字符）：lg6d46d0d0}

接下来，将两段字符交替取出，组合成明文：

f + l = fl
a + g = ag
{ + 6 = {6
f + d = fd
e + 4 = e4
1 + 6 = 16
3 + d = 3d
f + 0 = f0
5 + d = 5d
9 + 0 = 90
0 + } = 0}

最终拼接出的明文是：flag{6fde4163df05d900}

最终 Flag： flag{6fde4163df05d900}

三、知识点总结

  • 栅栏密码：一种置换密码，将明文交替排列在不同的行中，再依次读取拼接成密文。破解难度随栏数增加而变大。
  • 解密方法：对于2栏栅栏密码，只需将密文对半分，然后依次取出两段的开头字符进行交替拼接，即可还原出明文。
  • CTF解题技巧：题目名字（如“小羊”对应“栅栏”）和描述中的数字（如“2个栅栏”）通常是极强的情报线索，能帮助你瞬间缩小解题范围。
