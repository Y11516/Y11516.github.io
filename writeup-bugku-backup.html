备份是个好习惯 - Bugku Web Writeup

2026年9月12日 Bugku CTF Web安全 源码泄露 / MD5弱比较

这道题是一道极其经典的 Web 综合题。它完美结合了“源码泄露”与“PHP 弱类型比较”两个核心知识点。这篇 Writeup 极其详细地记录了我的做题过程、踩坑经历以及背后的原理剖析，方便日后复习。

一、题目信息

  • 题目名称：备份是个好习惯
  • 题目平台：Bugku CTF
  • 题目类型：Web / 备份文件泄露 / PHP 代码审计 / MD5 弱比较
  • 靶场链接：http://160.202.254.160:19036
  • 涉及工具：浏览器、目录扫描器

二、解题过程（详细步骤与踩坑记录）

1. 第一步：寻找备份文件（源码泄露）

访问靶场首页，页面只显示了一串空字符串的 MD5 值（d41d8cd98f00b204e9800998ecf8427e）。结合题目名字“备份是个好习惯”，我意识到这题大概率存在网站源码的备份文件泄露漏洞。

常见的备份文件后缀有：.bak、.swp、.zip、.rar、~ 等。

我尝试访问：http://靶场IP/index.php.bak，成功下载了源码文件！

2. 第二步：代码审计（发现过滤与弱比较）

打开下载的 index.php.bak，分析 PHP 代码逻辑：

<?php
include_once "flag.php";
ini_set("display_errors", 0);
$str = strstr($_SERVER['REQUEST_URI'], '?');
$str = substr($str, 1);
$str = str_replace('key', '', $str);
parse_str($str);
echo md5($key1);
echo md5($key2);
if(md5($key1) == md5($key2) && $key1 !== $key2){
    echo $flag."取得flag";
}
?>

代码逻辑分析：

  • 过滤机制：代码通过 str_replace('key', '', $str); 把参数名中的 key 字符串删除了。这意味着如果直接传 ?key1=xxx，它会被过滤成 ?1=xxx，导致 $key1 变量未定义。
  • 绕过方法：利用双写绕过。传入 ?kkey1=xxx。字符串 kkey1 被删掉 key 后，正好剩下 1，并没有变成 key1。我意识到必须让参数里包含两次 key，因此改为传入 kekeyy1，删除一次后正好剩下 key1，成功将值赋给了变量 $key1。
  • 弱比较条件：代码要求 $key1 != $key2 且 md5($key1) == md5($key2)。使用的是弱类型比较运算符 ==。

3. 第三步：利用 MD5 魔术哈希（Magic Hash）

在 PHP 中，== 比较两个字符串时，如果字符串以 0e 开头且后面全是数字，PHP 会把它们都当作科学计数法 0 来比较，即 0 == 0 为真。

我选取了两个经典的 MD5 值为 0e 开头的字符串：

  • QNKCDZO（MD5值为 0e830400451993494058024219903391）
  • 240610708（MD5值为 0e462097431906509019562988736854）

4. 第四步：构造 Payload 拿到 Flag

在浏览器地址栏输入：

http://靶场IP/index.php?kekeyy1=QNKCDZO&kekeyy2=240610708

回车后，成功绕过了过滤和比较逻辑，页面直接弹出了 Flag！

最终 Flag： flag{2ee9265e903c4d5089b6cb1caef7f7ce}

三、知识点总结（核心复习素材）

  • 1. 备份文件泄露漏洞：开发者在修改代码后，没有删除原来的备份文件（如 .bak），或者编辑器保存时生成了临时文件（如 .swp）。攻击者可以通过扫描这些文件下载到网站源码，从而进行代码审计。
  • 2. 字符串过滤绕过（双写）：当过滤逻辑是删除关键字时（如删除 key），可以通过重复该关键字来绕过（如传入 kekeyy1，删除中间一次后刚好得到 key1）。
  • 3. PHP 弱类型比较与 MD5 魔术哈希：== 是弱比较，会进行类型转换。当字符串以 0e 开头时，会被转换为科学计数法的 0，导致两个完全不同的输入在比较时变为相等。防御方法是使用强类型比较 ===。
