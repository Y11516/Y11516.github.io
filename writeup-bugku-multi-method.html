多种方法解决 - Bugku MISC Writeup

2026年9月12日 Bugku CTF MISC Base64隐写

这道题名为“多种方法解决”，提示是 KEY{}，描述明确提到“你会得到一个二维码图片”。附件是一个 Windows 可执行文件 KEY.exe。由于我是 Mac 系统无法直接运行 exe，我利用了命令行工具对其进行了静态分析，最终成功提取出隐藏在其中的 Base64 图片数据。

一、题目信息

  • 题目名称：多种方法解决
  • 题目平台：Bugku CTF
  • 题目类型：MISC / 文件隐写 / Base64转码
  • 题目提示：KEY{}
  • 附件内容：KEY.exe
  • 涉及工具：Mac 终端（strings、grep、python3）

二、解题过程（详细步骤）

1. 分析现状，确定思路

下载附件得到 KEY.exe，在 Mac 上无法直接双击运行。结合题目描述“你会得到一个二维码图片”，说明这个 exe 文件内部一定藏着一张图片。

2. 尝试直接提取 PNG 失败（踩坑记录）

我首先编写了一个 Python 脚本，试图通过搜索 PNG 的文件头（\x89PNG）直接从二进制数据中抠出图片。结果脚本报错提示“没有在文件中找到PNG图片”。这说明图片并不是以原始的 PNG 二进制格式存储的。

3. 搜索 Base64 编码特征，成功定位

既然不是原始格式，图片很可能被转换成了 Base64 字符串（以 iVBORw0 开头）。我使用了 strings 命令配合 grep 进行过滤：

strings KEY.exe | grep "iVBORw0"

终端瞬间输出了超长的一行字符串，这正是 PNG 图片的 Base64 编码！

4. Base64 解码，还原图片

我将这串 Base64 字符串导出保存，并使用 Python 进行解码：

strings KEY.exe | grep "iVBORw0" > base64.txt
python3 -c "import base64; open('flag.png','wb').write(base64.b64decode(open('base64.txt','r').read().strip()))"

命令执行完毕后，桌面上成功生成了 flag.png。

5. 扫描二维码获取 Flag

使用手机微信或在线二维码扫描工具扫描 flag.png，成功得到了最终的 Flag。

最终 Flag： KEY{dca57f966e4e4e31fd5b15417da63269}

三、知识点总结（核心复习素材）

  • 1. 二进制文件静态分析：当无法运行目标程序时，利用 strings 命令提取其中的可打印字符串，是快速排查隐藏明文、Base64 编码等信息的最高效手段。
  • 2. Base64 编码特征：PNG 图片的 Base64 编码通常以 iVBORw0 开头，JPEG 图片通常以 /9j/ 开头。掌握这些特征能够帮助我们在海量数据中快速定位图片资源。
  • 3. 命令行与 Python 联动：熟练使用管道符 |、重定向 >，配合一行 Python 命令，能极大提高数据提取与转换的效率，省去手动复制粘贴的麻烦。
