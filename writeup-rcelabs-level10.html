RCE-Labs Level 10 - od 命令八进制转储

2026年10月3日 RCE-Labs 黑名单绕过 数据编码

一、题目信息

  • 题目名称：RCE-Labs Level 10 (od 命令八进制转储)
  • 靶场链接：http://靶机IP:8080/less-10/
  • 涉及工具：浏览器

二、解题步骤

1. 分析题目考什么

黑名单已经累加到令人发指的地步，几乎把之前用过的所有面向文本行的查看工具（如 cat、tail、nl、sort、uniq）全部封禁。题目提示使用 od 命令，标志着我们的视角从“读取文本行”转为了“读取底层字节流”。

2. 怎么解（详细步骤与踩坑记录）

源码核心逻辑

$pattern = '/cat|tac|head|tail|more|less|nl|sort|uniq|rev/';
if(!preg_match($pattern,$cmd)){
    system($cmd);
}

踩坑记录：直接读取导致乱码

尝试 Payload：?cmd=od /flag

失败响应：页面输出了一长串类似 0000000 067141 020173 062124 020137 024505 071501 020137 043501... 的八进制数字。虽然读取成功，但人类无法直接阅读。

原因分析：od（Octal Dump）默认使用八进制形式转储文件内容，它不关心文件是文本还是二进制，只按字节输出。

改进方式：使用 od 的参数来格式化输出。例如 -c 参数以 ASCII 字符显示，-A x -t x1z 以十六进制显示。

最终成功 Payload

使用 -c 参数将字节转化为可读字符：

?cmd=od -c /flag

或者使用 -t x1 转成十六进制后手工解码（可以配合 Burp 或在线工具）：

?cmd=od -A x -t x1z /flag

成功响应：页面回显明文 flag{TEST_Dynamic_FLAG}。

3. 怎么迁移（跨学科与跨领域联想）

  • 数字取证与逆向工程：在分析恶意软件或磁盘镜像时，文件通常不包含明文，必须使用 xxd、od、hexdump 查看十六进制结构，分析文件头（Magic Number）来确定文件类型。
  • 信息论与数据编码：同一个信息（flag），可以用 ASCII 文本、八进制、十六进制、Base64 等无数种编码来表示。这体现的是计算机底层“万物皆 0 和 1”的思想，不同的编码只是对这串二进制流的不同可视化解释。

三、名词大全与原理深度复盘

1. 字节流 (Byte Stream)

计算机在底层处理文件时，不区分“文本”、“图片”或“视频”，一律看作连续的字节序列。od 命令就是直接对接字节流的工具，绕过了 Shell 的文本行概念，这也是它能无视黑名单顺利读取的本质。

2. 八进制 (Octal) 与 十六进制 (Hexadecimal)

因为二进制（0和1）对人类阅读太长，发明了八进制（0-7）和十六进制（0-9, A-F）来简化表示。1 字节（8 位）二进制恰好可以表示为 2 位十六进制数，或 3 位八进制数。

3. ASCII 码

美国信息交换标准代码。规定了字母、数字、符号与数字（如 'A' 是 65，'a' 是 97）的映射关系。od -c 之所以能让乱码变明文，就是因为它把读取到的字节按其数值翻译成了对应的 ASCII 字符。

四、题目思考

1. 这跟前面关卡的区别

Level 1-9 考的是“按行读取的文本工具替换”，而 Level 10 则跳出了“文本”限制，进入了“字节/编码”的世界。此时拦截的关键词不再是纯粹的动词（如 read, show），而是底层的转储工具（如 dump, hex）。

2. 这种题目的出现原因（底层逻辑与历史原因）

在计算机发展早期，许多系统没有显示器，程序员使用电传打字机在纸带上打孔来记录数据。为了排查二进制文件或系统状态，需要一种工具能把所有的字节转储成人类可读的八进制或十六进制格式。于是 1971 年，od 命令随着 Unix v1 诞生，并一直保留至今。只要系统还有二进制文件，这种底层的查看需求就永远存在。

3. 这种漏洞在实际中的应用

在 Web 渗透中，如果对方的 flag 是加密的，或者目标系统是一个没有 cat 命令的精简版 Alpine/Docker 容器，使用 od 或 xxd 就是最后的杀手锏。它常用于从被限制的环境中提取二进制数据（如编译好的提权 EXP）。

4. 如何抽象理解概念（大白话）

把读取文件比作“读一本书”。cat 是按照章节正常阅读；tail 是看最后几页；而 od 则是把这本书用显微镜观察，把每一个字的笔画、颜色代码、纸张纹理全部用数字打印出来。虽然看起来是乱码，但只要明白编码规则（比如把数字转回字符），就能还原出书本的内容。
