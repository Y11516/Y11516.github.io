把猪困在猪圈里 - Bugku MISC Writeup

这道题的名字是一个极其巧妙的双关语提示，它结合了数据编码（Base64）和古典密码学中的“猪圈密码”。这篇 Writeup 详细记录了我从提取图片到图形识别的完整推理过程。

一、题目信息

  • 题目名称：把猪困在猪圈里
  • 题目平台：Bugku CTF
  • 题目类型：MISC / Base64 / 猪圈密码（Pigpen Cipher）
  • 附件内容：file (2).txt（包含大量 Base64 编码和干扰字符 `A`）
  • 涉及工具：在线 Base64 转图片工具、猪圈密码在线解码器 / 对照表

二、解题过程（详细步骤）

1. 破解题目名称的线索

题目名叫“把猪困在猪圈里”。这里的“猪”和“猪圈”是在疯狂暗示一种古老的替换密码——猪圈密码（Pigpen Cipher）。这是一种用几何图形（井字格、X字格）来替换英文字母的密码。

2. 识别并提取隐藏图片（Base64 转码）

打开下载的附件 file (2).txt，发现里面是：

/9j/4AAQSkZJRgABAQ...（大量看似乱码的字符）
AAAAAAAAAAAA...（非常多的干扰字符 A）

我看到开头 /9j/ 非常眼熟。这是 JPEG 图片的 Base64 编码特征（Base64 图片通常以 /9j/ 开头，以 == 或 = 结尾）。而末尾的一大堆 `A` 是出题人用来伪装成普通文本的干扰项。

我将 /9j/ 开头到最后一个有意义字符的 Base64 代码全选复制，打开在线“Base64 转图片”工具粘贴进去。工具成功生成了一张图片。

3. 识别并解码猪圈密码

下载并打开这张图片，图片上画的是一些由三角形、井字格、X字格组成的几何符号。这正是**猪圈密码**的特征。

我搜索了一张“猪圈密码对照表”，对照着图片上的图形，逐个翻译出了英文字母，最终拼凑出了 Flag。

最终 Flag： flag{...}（请替换为你跑出来的真实答案）

三、知识点总结（核心复习素材）

  • 1. Base64 文件头特征识别：遇到不明字符串，注意看开头。`/9j/` 是 JPEG 图片的 Base64 标志；`iVBORw0KGgo` 是 PNG 图片的 Base64 标志。掌握这些特征，能帮助你在“乱码”中快速识别数据的真实类型。
  • 2. 猪圈密码（Pigpen Cipher）：

    这是一种简单的替换密码。它使用井字格（#）和 X 字格（X）的各个部分（上、下、左、右、以及内部加点）来对应 26 个英文字母。在 CTF 中，通常以图片形式给出，需要借助对照表进行翻译。

  • 3. 双关语线索：CTF 题目名称往往藏着巨大的提示。当看到“猪”或“圈”等字眼时，要条件反射地想到“猪圈密码”。
