PHPINFO - CTFHub Web 入门 Writeup

2026年9月16日 CTFHub Web安全 信息泄露 搜索技巧

这道题是“信息泄露”专项的经典题目。服务器直接输出了 phpinfo() 的页面，把底层的环境变量、PHP配置、系统信息全盘托出。面对几万行的数据，我第一次尝试用终端 curl | grep 搜索失败，最终通过改变搜索关键词，用 Cmd + F 成功找到了隐藏在环境变量中的 Flag。

一、题目信息

  • 题目名称：PHPINFO
  • 题目平台：CTFHub
  • 题目类型：Web / 信息泄露 / 环境变量泄露
  • 涉及工具：浏览器（Cmd + F 搜索）、Mac 终端（curl + grep）
  • 最终Flag： ctfhub{37817f1e47a7aaa0b721378a}

二、解题过程（详细步骤与踩坑全记录）

1. 现象：满屏的“天书”

启动靶场后，页面呈现出一个巨大的表格，包含了 PHP Version 7.3.14 以及大量的配置项、环境变量和服务器信息。新手看到这个页面会产生强烈的恐惧感：“这么多数据，我该从哪里看起？”。千万不要试图一行一行去阅读。

2. 踩坑：终端 curl + grep 搜索关键词错误

为了省事，我尝试在终端直接抓取并过滤 Flag。输入了以下命令：

curl -s http://challenge-69253d8803c59103.sandbox.ctfhub.com:10800/ | grep -i "ctfhub"

结果：只搜到了网页标题 <title>CTFHub 技能学习 | phpinfo</title>，并没有找到 Flag。

原因分析：出题人不会把环境变量的名字直接命名为 ctfhub。如果盲目搜索这个关键词，只能搜到一些无效的页面元素。

3. 成功破局：改变关键词，用 Cmd + F 搜索

既然终端搜不到，我回到浏览器。按下 Cmd + F 调出搜索框。

这一次，我不搜 flag 或 ctfhub，直接搜 ctfhub{（这是 Flag 的真面目）。

页面立刻高亮定位到了 Environment（环境变量）区块中的一行：

ctfhub{37817f1e47a7aaa0b721378a}

成功拿到 Flag！

三、知识点总结（往脑子里装的东西）

  • phpinfo() 函数： PHP 内置的调试函数，输出服务器极其详细的配置信息。在生产环境中绝对不允许存在，否则就是严重的信息泄露漏洞。
  • 环境变量泄露： 很多时候，运维人员会将数据库密码、API Key 甚至 Flag 写入系统的环境变量（Environment Variables）。phpinfo() 会把这些变量全部打印出来。
  • 搜索关键词的选择： 永远不要用太宽泛的词（如 `flag`）。Flag 的格式是 `ctfhub{...}`，直接搜完整格式，或者搜独特的前缀，能极大地提高命中率。

四、踩坑启示录（实战经验）

💡 不要被信息量吓倒：信息安全中，面对海量数据，工程师的第一反应应该是“用什么工具过滤”而不是“我该怎么看完”。浏览器自带的 Cmd + F 就是最简单、最强大的工具。

💡 终端搜索的局限性：虽然 `curl | grep` 很帅，但遇到 HTML 结构复杂、元素分散的页面，很多时候不如浏览器直观。知道什么时候用终端（如二进制的 strings），什么时候用浏览器（如结构化的 HTML 页面），是实战中必须积累的经验。

做一道题，就要往自己脑子里装点东西。
