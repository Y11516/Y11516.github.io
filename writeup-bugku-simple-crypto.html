简单加密 - Bugku Crypto Writeup

2026年9月14日 Bugku CTF Crypto ASCII偏移 / Base64编码

这道题名为“简单加密”，分类为 Crypto（密码学）。题目只给出了一串看起来乱码的字符串，以及提示 key{}。这是一个经典的“编码转换+基础逆向”题目。

一、题目信息

  • 题目名称：简单加密
  • 题目平台：Bugku CTF
  • 题目类型：Crypto / 编码转换
  • 题目提示：key{}
  • 密文： e6Z9i~]8R~U~QHE{RnY{QXg~QnQ{^XVlRXlp^XI5Q6Q6SKY8jUAA
  • 最终Flag： key{68743000650173230e4a58ee153c68e8}

二、解题过程（详细步骤与逻辑剖析）

1. 观察密文，寻找破绽

操作步骤：拿到密文后，先不要急着用工具，而是仔细观察字符串的特征。

目的是什么？快速识别出它可能经过了哪种加密或编码。

背后的逻辑：字符串末尾是 AA。在常规的编码体系中，Base64 编码的字符串常常以 = 或 == 结尾来补位。这给了我们一个极大的暗示：这可能是一个被**偏移处理过的 Base64 编码**。

2. ASCII码偏移还原

操作步骤：寻找规律。已知 = 的 ASCII 码是 61，而 A 的 ASCII 码是 65。65 - 61 = 4。这说明密文很可能是将正确的 Base64 字符**全部减去 4**（或 ASCII 码向左偏移 4 位）后得到的。

用代码批量还原（Python脚本）：

cipher = "e6Z9i~]8R~U~QHE{RnY{QXg~QnQ{^XVlRXlp^XI5Q6Q6SKY8jUAA"
plain_base64 = "".join(chr(ord(c) - 4) for c in cipher)
print(plain_base64)

执行结果：我们成功还原出了未被偏移处理的 Base64 字符串：a2V5ezY4NzQzMDAwNjUwMTczMjMwZTRhNThlZTE1M2M2OGU4fQ==。

背后的逻辑：CTF中常通过简单的加减操作来隐藏原始编码。在这个操作中，对所有字符的 ASCII 码减 4，即可恢复成标准的 Base64 字符串。

3. Base64 解码，拿到最终 Flag

操作步骤：使用在线 Base64 解码工具（或者随波逐流工具），将上一步得到的字符串 a2V5ezY4NzQzMDAwNjUwMTczMjMwZTRhNThlZTE1M2M2OGU4fQ== 进行解码。

结果是：key{68743000650173230e4a58ee153c68e8}。

背后的逻辑：解码后的字符串刚好符合题目提示的 key{} 格式，这正是我们苦苦寻找的 Flag。

三、踩坑与代码迭代全过程（为什么会失败？）

这道题看似简单，但在实际操作中，新手很容易走进死胡同：

第一次迭代：直接用Base64解码密文

报错：把原文 e6Z9i~]8R~U~QHE{...}AA 扔进 Base64 解码器。

为什么错？因为原文包含 ~、]、^ 等字符，它们不是 Base64 的合法字符，解码器会直接报错或乱码。

第二次迭代：注意末尾的“AA”，尝试猜测

操作：看到了末尾的 AA，很多同学会猜测是不是把 == 替换成了 AA？

遇到的问题：如果只是替换末尾，变成了 ...UAA 变成 ...U==？但中间的字符依然是乱码。

为什么失败？因为出题人不是简单的“替换”，而是做了“**整体的 ASCII 码偏移**”。如果只是替换末尾，中间部分是解不出来的。

第三次迭代：找出偏移量，全量平移

改动：分析出 A(65) 到 =(61) 差了 4。使用 Python 或随波逐流工具中的“ASCII码偏移”功能，将密文每一个字符的 ASCII 码减去 4。

原理与逻辑：这就是密码学中简单的“凯撒密码”的变种——ASCII 码位移。统一偏移后，得到了标准的 Base64 字符串，最后一步解码就顺理成章地拿到了 Flag。

四、名词解释大全（你需要知道的基础概念）

1. ASCII码

美国信息交换标准代码。计算机中，每一个英文字母、数字、符号都对应一个十进制数字（比如 'A' 对应 65，'a' 对应 97）。本题就是利用了不同字符之间的数字差来进行加密。

2. ASCII码偏移

一个字符在 ASCII 码表中的数值增加或减少特定的数值，从而变成另一个字符。例如 'A'(65) 减 4 得到 '='(61)。常用于 CTF 中对字符串进行简单的混淆。

3. Base64 编码

一种基于 64 个可打印字符来表示二进制数据的表示方法。它常用于在网络中传输数据。特征：通常由大小写字母、数字、+、/ 组成，末尾常有 0 到 2 个 '=' 作为填充。

4. 随波逐流 (工具)

一款在线的 CTF 综合解密工具（网页版）。它集成了编码转换、进制转换、ASCII码偏移还原、各种密码爆破等功能。新手遇到乱码时，可以往里面一扔，往往能自动识别出加密方式。

5. Crypto (密码学)

CTF 中的一大分类，主要涉及现代密码学（如 RSA、AES）和古典密码学（如凯撒密码、栅栏密码、维吉尼亚密码）以及各类编码转换（Base系列、URL编码等）。

五、这道题到底在考察什么？

这道题是一道非常经典的新手过渡题：

  1. 观察力与敏感度：能否从末尾的 AA 联想到 Base64 的 == 补位特征。这是破题的关键。
  2. 基础编码知识：考察对 ASCII 码表和 Base64 编码原理的理解。
  3. 简单逆向思维：看到密文，能反向推导出加密逻辑（65 - 4 = 61），并应用同样的逻辑进行解密。
  4. 工具使用能力：当手动写脚本或计算太慢时，能否高效使用“随波逐流”这类在线工具来快速定位和解答。
